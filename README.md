# Nykaa Fashion — curation-first redesign (prototype)

A responsive-web redesign of Nykaa Fashion's discovery experience, built from [`docs/PRD.md`](docs/PRD.md). Discovery is led by **taste, not discount**: Hidden Gems, Luxe, the Responsible Edit, Festive and House of Nykaa are first-class destinations; a discount is shown only where a price has genuinely moved.

> **This is a design prototype.** Products, labels, stories and people are fictional (House of Nykaa label names are used as named in the brief). Checkout, payments, OTP sign-in, orders, tracking, reviews and personalisation are **simulated** and labelled as such. No payment is taken and no order exists.

See [`PROJECT_STATUS.md`](PROJECT_STATUS.md) for milestones, decisions and QA, and `/prototype` in the running app for reviewer notes.

## Stack

Next.js 16 (App Router, Cache Components, Turbopack) · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide. No other runtime dependencies. Mock JSON-style data modules and `localStorage` persistence, structured so real APIs can slot in.

## Commands

```bash
npm install
npm run dev               # dev server
npm run build && npm start
npm run typecheck && npm run lint
npm run data:check        # validate every cross-reference in src/data
npm run art:manifest      # build the image-render manifest from catalogue + scene data
npm run art:render        # render imagery (scripts/art) into public/img
```


## Imagery

No photo host was reachable when this was built, so imagery is generated by `scripts/art` from the catalogue data and written to `public/img/<key>.webp` (keys live in `src/data/catalog.ts` and `src/data/scenes.ts`). **Replace any file with a photograph of the same name and nothing else changes.** `src/data/generated/image-meta.json` holds each image's average colour (used as the loading placeholder) and the pin positions for shoppable editorial images.
